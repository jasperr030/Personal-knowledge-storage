# 个人知识库

这是覆盖生活、学习、兴趣、技术与个人工作经验的长期知识库，不限于编程或工作问题。
Markdown 是原始资料，Git 保存版本，家里 Windows 主机提供检索，公司 Ubuntu 是轻量客户端。

## 先读什么

- [跨设备交接说明](docs/CODEX-HANDOFF.md)：家里与公司端共用的架构、地址、启停及同步流程。
- [知识整理约定](docs/KNOWLEDGE-GUIDE.md)：笔记分类、来源、验证状态和模板。
- [用户偏好与已确认决策](CONTEXT.md)：值得跨聊天保留的长期背景。
- [Codex 项目约定](AGENTS.md)：在此仓库工作时的操作约定。

## 内容范围与目录建议

先记录，再逐步整理；目录不是强制要求，也不需要预先创建空目录。

| 目录 | 内容举例 |
| --- | --- |
| `inbox/` | 临时收集、待整理资料 |
| `life/` | 家居、饮食、健康常识、旅行、消费与日常经验 |
| `learning/` | 阅读、语言、课程与通用学习方法 |
| `interests/` | 游戏、运动、摄影等兴趣 |
| `technology/` | 编程、硬件、工具与技术排查 |
| `work/` | 可合法保存的个人方法和经验 |
| `docs/` | 知识库本身的说明和操作手册 |

生活类与技术类笔记使用相同的检索流程，无需另外部署模型或数据库。

## 同步的含义

Git 同步 Markdown 和说明文件；MCP 搜索家里最近成功建立的索引。
两台电脑的 Codex 聊天记录不会因为接入 MCP 自动互通，重要结论需要写成文件。

公司端在本仓库中执行 `git pull --ff-only` 获取最新说明，随后让 Codex 阅读
`AGENTS.md`、`CONTEXT.md` 和 `docs/CODEX-HANDOFF.md`。
家里拉取笔记后，运行中的服务最多五分钟内自动扫描索引；目前没有定时 Git 拉取。
